# NOCLIP — Aventure dans les Backrooms

## Présentation

NOCLIP est un jeu d'aventure textuel réalisé dans le cadre
d'un mini-projet d'initiation au HTML et au CSS.

Le joueur traverse différents lieux des Backrooms.
Ses choix déterminent son parcours et conduisent à quatre fins :
perdu en mer, disparition, retour à la réalité ou faux retour.

Le jeu comprend 17 pages, accueil compris,
ainsi qu'une page présentant l'arbre de navigation.

## Lancer le jeu

1. Télécharger le projet et décompresser le dossier si nécessaire.
2. Ouvrir `index.html` dans un navigateur.
3. Utiliser les boutons pour avancer dans l'histoire.

Aucune installation ni connexion à Internet n'est nécessaire
pour jouer à cette version.

## Technologies

- HTML : structure, textes et liens entre les pages.
- CSS : couleurs, décors, boutons et adaptation aux écrans.
- Aucune bibliothèque externe.

## Organisation

- `index.html` : accueil.
- `style.css` : styles communs.
- `pages/` : scènes et fins de l'aventure.
- `assets/images/C : dossier réservé à d'éventuelles images.
- `acceuil.html` : le deuxiême accueil
- `arbre-navigation.html` : carte des chemins, imprimable.
- `arbre-navigation.pdf` : version PDF de cette carte.

## Choix de conception

Les décors sont dessinés avec des dégradés et des formes CSS.
Les boutons comportent des symboles ou des emojis.

Certains chemins se rejoignent, mais les lieux visités donnent
des informations différentes. Les bureaux et l'hôtel contiennent
notamment des indices utiles pour les décisions suivantes.

Les quatre fins permettent de rejouer avec d'autres choix.

## Exporter l'arbre en PDF

1. Ouvrir `arbre-navigation.html` dans le navigateur.
2. Utiliser Ctrl+P.
3. Choisir « Enregistrer au format PDF ».
4. Choisir l'orientation paysage.
5. Enregistrer sous `arbre-navigation.pdf`.
